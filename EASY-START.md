# 🚀 BHARAT YATRA - EASY START GUIDE

## **3 Simple Steps - Just Double-Click!**

### **Step 1: Install Dependencies** (First time only)
Double-click this file:
```
1-SETUP.bat
```
✅ Wait for it to complete (2-3 minutes)

---

### **Step 2: Start Backend Server**
Double-click this file:
```
2-START-BACKEND.bat
```
✅ Wait for message: `Started TravelBuddyApplication...` (60-120 seconds)
✅ **Keep this window open!** Do NOT close it!

---

### **Step 3: Start Frontend Server**
Open **another Command Prompt** and double-click:
```
3-START-FRONTEND.bat
```
✅ Wait for message: `Local: http://localhost:5173/`
✅ **Keep this window open!** Do NOT close it!

---

## **Final Step: Open Browser**

Copy and paste this URL in your browser:
```
http://localhost:5173
```

✅ **You should now see Bharat Yatra landing page!**

---

## **IMPORTANT**

⚠️ **Keep BOTH Command Prompt windows open!**
- Window 1: Backend (2-START-BACKEND.bat)
- Window 2: Frontend (3-START-FRONTEND.bat)

If you close either window, the app stops working.

---

## **What You Can Do**

- ✅ Search for destinations
- ✅ Enter from city and destination
- ✅ View offers
- ✅ Click on any button

---

## **If Something Goes Wrong**

**Backend not starting?**
- Check if port 8080 is available
- Try running again

**Frontend not starting?**
- Make sure Step 1 (SETUP.bat) completed successfully
- Run it again if needed

**Can't see website?**
- Make sure both windows show success messages
- Try: http://localhost:5173 (not localhost:3000)
- Hard refresh: Ctrl+Shift+R
