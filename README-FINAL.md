1. Make sure you're using the CORRECT URL: `http://localhost:5173`
2. Keep both Command Prompt windows visible
3. Hard refresh browser: `Ctrl+Shift+R`
4. Close browser and open again
5. If still issues, run `AUTO-START.bat` again
